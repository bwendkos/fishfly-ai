# Social Cards

OG (Open Graph) images for social sharing. Generate per launch / per major content piece.

Target dimensions: **1200 × 630px** (Twitter / LinkedIn / Facebook spec).

## Planned cards

- `og-default.png` — Generic FishFly share card (logo + tagline on cream)
- `og-library.png` — Saltwater Fly Library specific
- `og-fly-trip-scout.png` — Fly Trip Scout specific

## Generation approach

Can be designed in HTML/CSS at exactly 1200×630, then screenshot via Puppeteer / Playwright. Or designed in Figma and exported.
